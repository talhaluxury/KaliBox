# Changelog

## 1.0.0
- Initial release: Kali (NetHunter arm64 rootfs) via proot on non-rooted phones.
- Terminal with tabs, extra-keys row, pinch-zoom, colour schemes, hardware-keyboard shortcuts.
- XFCE desktop over localhost-only TigerVNC + noVNC in a WebView, touchpad mode, resolution presets.
- Resumable rootfs download with SHA256 verification, backup/restore, tool bundle installer.
- GitHub Actions build (debug always, signed release when secrets exist).
